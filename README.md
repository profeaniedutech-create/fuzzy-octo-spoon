# Profe Ani Edutech

Sitio web educativo dedicado a compartir recursos innovadores para docentes de Educación Primaria.

## Sobre el proyecto

Profe Ani Edutech es un espacio diseñado para brindar herramientas pedagógicas, secuencias didácticas, proyectos ABP, actividades STEAM, recursos digitales e integración de Inteligencia Artificial aplicada a la educación.

## Objetivos

- Compartir materiales educativos de calidad.
- Promover metodologías activas e innovadoras.
- Facilitar el uso de tecnologías digitales en el aula.
- Impulsar la integración de la Inteligencia Artificial en la enseñanza.

## Contenidos

- Secuencias didácticas.
- Proyectos ABP.
- Actividades STEAM.
- Recursos para efemérides escolares.
- Herramientas de IA para docentes.
- Materiales descargables.
